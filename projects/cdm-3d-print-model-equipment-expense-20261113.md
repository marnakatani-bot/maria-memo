# CDM立体模型・3Dプリント設計仕様と研究設備経費計画

**記録日：2026-11-13／作成対象：GitHub maria-memoの制作仕様メモ**
**著者の希望：** 「3Dプリンターほしいよね。立体模型にしたいわ。幼児のおもちゃとか」「3Dプリンター用の模型仕様メモを作る。経費設定しよう！ おニューのスペックアップデートした老眼にも優しい大きめパソコンと3Dプリンター。中古も可能」

**現在の状態：企画・仕様と予算の設定まで。CAD / STL / 3MFの設計ファイル、印刷実験、機材購入、税務帳簿への計上は未実施。**

## 1. 研究目的と製作物の位置づけ

CDM（意識の次元マッピング）の観測視座の等価性、重なり、3・6・9の関係、観測目的による説明中心の切り替えを、画面上の図から「手で触れて動かせる模型」へ翻訳する。研究者向けには図形や関係を確認する教材、一般向けには回して見せられる展示・動画撮影用模型、将来的には幼児の知育玩具のように直感的に触れるデザインを目指す。

幼児玩具のような見た目と使い心地を採用するが、**初期成果物は成人向け研究・展示試作品**である。子どもに渡す製品としての安全性・耐久性・法令適合は、別工程で確認する。

研究上の正本は[CDM公式GitHub原典](https://github.com/marnakatani-bot/maria-dimension-map-)。模型は原典の説明・観測補助として作成し、模型の都合で公式定義を変更しない。

## 2. 原典と現物の照合（2026-11-13現在）

照合した現物：

- [公式 README：次元構造モデル・視座表](https://github.com/marnakatani-bot/maria-dimension-map-/blob/main/README.md)
- [Seed of Life型構造図（現行PNG）](https://github.com/marnakatani-bot/maria-dimension-map-/blob/main/docs/images/cdm-structure-seed-of-life.png)
- [6D鏡面・プロセス図（現行PNG）](https://github.com/marnakatani-bot/maria-dimension-map-/blob/main/docs/images/cdm-process-diagram.png)
- [RS022質問③：中心の選択と369の幾何](https://github.com/marnakatani-bot/maria-memo/blob/main/theory/02_構造原理/RS022_③_369の幾何学と観測目的による中心の選択.md)

**保持条件：** 各次元はSeed of Life型の立体構造の中で、幾何学的に重なり合い同時に成立する対等な観測視座。9Dは現行の構造表示における中心、周囲の六円は3D・4D・5D・6D・7D・8D。現物の平面投影は上から時計回りに3D→4D→5D→6D→7D→8D。3Dと6Dは中央9Dを挟む対向位置。6Dは観測不成立であり、7D〜9Dでは人間の位置は媒体。

**中心の切り替えの二層：** 構造模型は9D中心の現行配置を保つ。説明対象を3D・6D・9Dなどへ切り替える表示・操作は、注目位置を変更するための仕組みとして追加する。説明上の中心が自在であることは、原典の数学的中心を任意に動かせるという定理を意味しない。

**プロセス図との関係：** 6Dを境界にしたプロセス表示は、構造模型とは別モード・別模型にする。これらを単純に同じ座標配置へ押し込まない。

## 3. 最初に作る模型の設計仕様

### M0：手で触れるSeed of Life型の小型試作品（優先・検収用）

**方式：** FDM/FFF 3DプリンターによるPLA製「2.5Dの立体レリーフ」。円の輪郭が互いに重なる様子を、段差・盛り上がり・色分けで見せる。**平面構造図の触覚化**であり、これをもってCDMの三次元幾何学の完全な実体模型とは称さない。

| 項目 | 暫定設計値・要件 |
| --- | --- |
| 基本配置 | 9D中央、3D上、4D右上、5D右下、6D下、7D左下、8D左上 |
| 円の数 | 7円（中央1＋周囲6） |
| 円の配置 | 周囲六点を中心から等距離に置き、円どうしが重なる構造 |
| 小型版サイズ | 円の半径 r=34mm、周囲の中心までの距離 s=45mm。輪郭の最大直径は 2×(r+s)=158mm。基台は直径168mm以内 |
| 最初のプリンター適合 | Bambu Lab A1 miniの造形可能範囲180×180×180mmを満たす（配置・ベッドの実測余白はスライサーで再確認） |
| 基台・輪郭 | 基台厚さ4mm目安、円の線幅3〜5mm、浮き上がり1.5〜3mm。細部はCAD上で調整 |
| 表示 | 数字3D〜9Dは幅広い線の凸文字、目安高さ12〜16mm。小さな説明文は基台に詰め込まず別紙に回す |
| 色 | 色識別＋形・数字による識別。中心9Dを紫系、6Dを灰系とする既存図の配色は参考。色覚の違いでも数字が読み取れること |
| 可動 | 初版は一体型、後続版で回転台・基点を指す大きなポインターを追加 |
| 部品の固定 | 外れやすい小径磁石・小球・小ネジを使わない。必要な場合は成人向け試作として別途設計 |
| 材料 | 単色PLAを標準。色は塗装や色替えで試す。PETGは耐衝撃・耐熱の必要が明確になった段階で比較 |
| スライス初期値 | 0.4mmノズル、0.20mm積層、外周3周、充填15〜20%を初期値として試験。材料・形状に応じて変更 |
| データ成果物 | パラメトリックCAD原本（FreeCADまたはOpenSCAD）、STL、印刷設定を保存した3MF、撮影写真、検収記録 |

**配置の設計用座標（試作仕様。公式の369正三角形座標ではない）：**

2D座標で9Dを(0,0)、周囲中心距離をsとする。yを上として以下を置く。

| 視座 | x | y |
| --- | ---: | ---: |
| 9D | 0 | 0 |
| 3D | 0 | +s |
| 4D | +√3s/2 | +s/2 |
| 5D | +√3s/2 | −s/2 |
| 6D | 0 | −s |
| 7D | −√3s/2 | −s/2 |
| 8D | −√3s/2 | +s/2 |

各円は半径r。座標の目的は**公開PNGの見た目を可調整なモデルへ移すこと**。原典のSeed of Life型多次元立体を数学的に立証する座標系と混同しない。

### M1：大きめ・中心切り替えを見せる展示モデル（次段階）

- 推奨外径：約224〜230mm（r=45mm、s=62mm → 輪郭214mm、基台224〜230mm）。Bambu Lab A1の256mm造形領域で一体造形を目指す。
- 回転台を付けて、360°回せる。台座は一体型の回転ジョイントなどを優先し、工具なしで小部品が外れる設計を避ける。
- 観測・説明の焦点を3D・6D・9D等へ動かせる**指示マーカー**を付ける。大きさと構造は子ども向けに安全性を確保できるまで成人用。
- 円の重なりをより視認しやすくするため、段差付きリング・透明板による重層・輪郭の色分けを比較する。FDMの「透明PLA」は完全透明ではないため、透明を前提とした構造は素材選定後に試す。
- 目標：机上で複数人に説明でき、動画撮影時にも各数字・輪郭が識別できること。

### M2：369・6D鏡面・真の立体模型（研究用・別工程）

9Dの幾何学的中心表示と、3・6・9が正三角形を構成する立体モデルは、**定義と座標の整合を先に確認した上で**CAD化する。RS022で参照された「9Dに高さを与えると正三角形」というモデル内定理、3→6の辺（4・5）、6→9の辺（7・8）、9→3の帰還との関係を照合する。

この版はM0/M1と独立した数理・製作検査を持たせる。図面間の写像や回転操作が正確だと検証できるまで、M0の平面円配置をそのまま「369立体の証明模型」としない。

### 将来案：Flower of Lifeへの展開

複数の独立した観測主体を中心とするFlower of Lifeへの展開は、公式原典で「将来の展開可能性、未検証の探索的仮説」と位置づけられている。最初の模型へ確定仕様として組み込まず、M3以降のモジュール増設の研究課題とする。

## 4. 模型の検収基準（試作後）

- 7つの数字・位置関係・中央9D・下側6Dが既存の原典図と整合する。
- 円同士の重なり、3D↔6Dの対向、上下に絶対的な優劣を付けない可回転性が読み取れる。
- 「6D＝観測不成立」を、観測する人型の部品などで誤表現していない。
- 大きな文字・数字が明るい環境と動画撮影時に判読でき、見づらい説明文は別冊とする。
- FDMで反り・はがれ・破損が起こりにくく、積層方向と可動部分の強度を試せる。
- 角の丸み、破片の脱落、指挟み、接触部の摩耗、安定性を検査する。
- 子ども向けに提供する場合は、年齢別の誤飲・衝撃・化学物質・玩具安全基準の確認を別途実施する。

## 5. 新しい制作環境の条件

### 実機の現状（2026-11-13に接続済みPCから技術情報のみ取得）

- CPU：Intel Core i5-6200U（第6世代）
- RAM：約16GB
- OS：Windows 11 Pro
- 画面出力：1366×768px、画面の物理領域の取得値34×19cm（約15インチ級）
- GPU：Intel HD Graphics 520

**判断：** 現行PCは資料閲覧や軽い構成確認には活用できる。CAD編集・動画制作・多資料の同時表示・目の負担軽減を考え、CPU・SSD・メモリおよび外部モニターを更新する候補を立てる。GPUが必須となる高度な3Dレンダリング／動画処理は、実際の利用ソフトと作業内容を見て追加判断する。

### 更新PCの要求仕様

| 項目 | 最低条件 | 推奨 |
| --- | --- | --- |
| 種別 | Windows 11対応デスクトップ/小型PC（中古可） | 画面を大きく取れるミニPCまたは小型デスクトップ |
| CPU | Intel Core i5第12世代級 / AMD Ryzen 5近年世代級 | Intel Core i5第12〜14世代級またはRyzen 7 近年世代級 |
| RAM | 16GB | **32GB**（多資料、CAD、ブラウザ、動画編集用） |
| SSD | 512GB | 1TB以上・バックアップ別途 |
| GPU | 3D表示が動作する統合GPUで開始可 | 大規模レンダリング時のみ独立GPUを検討 |
| 画面出力 | 27インチQHDへの接続確認 | 32インチ4Kにも対応、HDMI/DP端子を購入前に照合 |
| 保守 | OSの正規ライセンス、実動作確認 | 中古は保証・返品条件・SSD状態・メモリ構成を確認 |

### 大画面・文字の見やすさを優先するモニター

**案A：27インチQHD IPS、非光沢、高さ調整**。例：Dell P2725D（2560×1440、100Hz）。参考直販価格2026-11時点で38,799円程度。資料を左右に並べる、文字を拡大する用途に向く。

**案B：31.5インチ4K、高さ調整**。例：Dell S3225QS（3840×2160、120Hz、VA）。参考直販価格は2026-11時点で54,979円前後。Windowsの表示倍率125〜175%を実際に試し、文字の大きさと視距離・視線の高さを調整する。32インチ4Kだから自動的に文字が大きくなるわけではないので、拡大設定まで含めて検収する。

既存PCに外部モニターを先に追加する段階導入も可能。現行機の映像出力端子と対応解像度は別途確認する。

| Bambu Lab **A1 mini**・新品 | 180×180×180mm | 2026年11月13日開始ブラックフライデー特価 **26,000円**（通常29,800円） | M0を一体造形。M1は分割印刷が必要 |
| Bambu Lab **A1**・新品 | 256×256×256mm | 日本公式掲載 **48,800円から**。購入時に対象構成と実価格を再確認 | M0・M1を一体造形しやすい |

A1 miniは全自動キャリブレーションを備えた導入向け。最初にM0を作る目的では合理的。完成した模型を大きく見せることまで想定すると、**約2.3万円の機種差額**と、後から分割印刷が必要になる手間を比べる。

推奨する初期材料：PLA 1kg×2色程度（単価例2,400円/巻）、簡単な仕上げ工具・保護具・予備ノズル等の予算3,000〜8,000円。色数は初版から7色を買い揃える必要はない。高温ノズル・換気・接触事故には注意し、設置場所に余白を取る。3D印刷中は換気と火災予防に配慮する。

**中古の判断基準：** 複数回のテスト印刷実績、ビルドプレートの損傷、ノズルやベルトの消耗、フィラメント供給機構、輸送時の破損、メーカー保証の継承条件、修理部品の入手性を確認。格安の中古機が故障・調整の負担を増やすなら、新品A1 miniの方が総費用を抑えやすい。

## 7. 研究設備の経費認定・取得予算（設計値）

著者の「経費設定しよう」という発言を、**CDM研究・発信に必要な制作設備として機能と予算を明示する記録**として採用する。取得資金や現物の入手を確約する意味ではない。現行のCDM「谷町経済」の着想とも関連するが、公式理論への新しい定義追加や実現保証は行わない。

| 取得方法 | PC | モニター | 3Dプリンター | 材料・工具 | **概算** |
| --- | ---: | ---: | ---: | ---: | ---: |
| **先行検証**：現行PCを活かす | 0円 | 約38,800円 | A1 mini 26,000円 | 約5,000円 | **約69,800円** |
| **標準案**：中古PCで制作環境を更新 | 約55,000円 | 約38,800円 | A1 mini 26,000円 | 約5,000円 | **約124,800円** |
| **大きめ模型・大画面重視案** | 中古PC約70,000円 | 約54,980円 | A1約48,800円 | 約7,000円 | **約180,780円** |

PC本体は中古品の掲載価格と相場から設けた**探索予算**。動作・保証・在庫を確認した購入確定価格ではない。合計は送料、SSD・RAM増設、バックアップ媒体、机上スペースの改善、税務・配送関連費用などで増減する。新品PCを選ぶ場合は、最終候補で改めて比較する。

**現時点の合理的な優先順位：** ①目に優しい27〜32インチの表示環境、②A1 miniでM0模型試作、③現行PCでのCAD作業負荷を計測してPCを更新、④大型M1の制作頻度が高ければA1の導入を優先する。新品A1とA1 miniの差額が制作時間・分割印刷の手間に見合う場合は最初からA1を選ぶ。

### 税務上の必要経費との区別

この企画メモの「経費設定」は**研究に必要な設備の予算認定**を指す。所得税での必要経費は、実際に取得して業務に使ったこと、事業利用割合、資産ごとの取得価額などによって扱いが決まる。国税庁2026年の案内では、業務用の1年未満・10万円未満の資産は一定の場合に当年経費にでき、10万円以上は減価償却または適用要件に応じた処理となる。青色申告者向け特例等は対象要件を確認する。私用と共用なら事業利用割合を合理的に記録し、領収書と利用目的を保存する。

**帳簿記入・税務判断は購入時に分離して実施**。ここでは支出や購入を行っていない。

## 8. 導入後の実行工程と判定条件

1. **CAD前検査**：公式PNGとRS022を照合し、3D〜9Dの配置・中心の指示と「M0は触覚化」「M2は真の立体」を分けた設計シートを確定する。
2. **M0 CAD作成**：FreeCAD / OpenSCADなどでr、s、基台径、円幅、文字高さをパラメータ化し、STLと3MFへ出力する。
3. **印刷設定と試作**：A1 miniまたはA1で小型試作品を印刷し、形状・可視性・積層方向・耐久性を確認する。
4. **研究監査**：既存の平面構造図と照合し、視座の配置・等辺性・中心の説明に齟齬があれば模型設計だけを修正する。原典の改変は別承認事項。
5. **M1展示版**：中心フォーカスマーカーと回転機構を追加し、動画で角度を変えても違いが見えるか検証する。
6. **M2研究版**：369立体・6D鏡面・プロセス表示の座標対応を専門的に検証してから造形する。
7. **児童向けに進む場合**：小部品・磁石・耐衝撃・部品脱落・樹脂の安全性・対象年齢・適用法令/玩具規格等を確認し、独立の製品設計として扱う。

**次の実務に必要な未確認事項：** 新PCを据置かノートにするかの運用希望、作業机の奥行とプリンター設置位置、動画・3Dレンダリングの負荷、成人向け試作の実物テスト結果、購入時点の価格・保証と在庫。これらはCAD初稿や機材の購入候補を絞る段階で確認する。
