# 公開SNS・媒体アーカイブ

中谷まり亜（Maria Nakatani）が各媒体で公開してきた記事・投稿の一覧を、媒体ごとに保存するフォルダ。意識の次元マッピング（Consciousness Dimension Mapping）の研究と発信の記録を、日付と住所でたどれるようにすることを目的とする。理論の正式な定義は [maria-dimension-map-](https://github.com/marnakatani-bot/maria-dimension-map-) を参照。

## 取得方法と範囲

- 各媒体が公開している情報だけを、公開API・公開アーカイブから取得した。ログインが必要な情報は含まない。
- noteの有料記事・メンバーシップ限定記事は、タイトル・公開日・住所のみを載せ、本文は載せない。
- YouTubeは動画タブの公開動画のみを収録し、限定公開・非公開・ショート動画は含まない。公開日は今回の取得方法では得られなかったため、チャンネルの表示順（新しい順）で並べた。
- Blueskyは本人の投稿と返信を収録し、他の人の投稿のリポストは含まない。本文は一覧では140字で切り、全文はCSVに収める。
- 本文の全文はこのフォルダに複製せず、各記事の住所から元の媒体で読む形にする。
