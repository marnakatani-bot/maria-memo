# 独立研究者だからできる「未来検証型・未検証仮説シリーズ」構想
タグ: #独立研究者 #未検証仮説 #Zenodo #DOI #未来検証 #研究公開

---

## 背景

2026年8月18日、Zenodoで未検証の大胆な仮説をDOI付きで残し、未来の科学と答え合わせする話から、まり亜はこう言った。

「独立研究者ならではって感じになってきた笑」

さらに、

「万が一読んだ誰かが、へーおもしろいって検証してくれるかもしれないしね？」

## 考察の要点

独立研究者は、所属組織や既存研究テーマの枠に合わせる必要が少ない。その自由を、思いつきを無責任に断定する方向ではなく、**未検証であることを明示した上で、未来に検証可能な形で公開すること**へ使う。

目的は「正しさを先取りして主張すること」ではなく、現在の観測・仮説・予測・棄却条件を時点固定し、後世や他者が検証できる研究資源として置くこと。

## 理論の詳細

仮称として `Impossible Hypotheses / Future-Testable Hypotheses` シリーズを設ける。

各記録には、①2026年時点の観測、②未検証の仮説、③成立するなら将来観測されるはずのこと、④反証・棄却条件、⑤公開日・版・DOI、⑥後年の検証結果を分けて残す。

重要なのは、未来の「当たった／外れた」だけではない。公開された仮説を読んだ別の研究者やAIが「面白い、検証してみよう」と動けば、その時点で仮説は他者の研究を発火させる役割を持つ。

## 統合対応表

| 要素 | 役割 |
|---|---|
| 独立研究者の自由 | 既存テーマ外の仮説も探索できる |
| 未検証ラベル | 事実・仮説を混同しない |
| DOI・版固定 | 「いつ何を言っていたか」を未来に残す |
| 予測・棄却条件 | 後世の答え合わせを可能にする |
| 公開 | 他者が検証へ参加できる入口をつくる |

## 未解決の課題

- シリーズ名とZenodo上の統一フォーマットを決める
- 既存のResearch Sketch・論文シリーズと明確に区別する
- 「面白い仮説」と「検証可能な仮説」の境界を各回で明示する
