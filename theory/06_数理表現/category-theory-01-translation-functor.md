# 圏論のはじまり：翻訳で変わるものと残るもの

- **記録日**: 2026-11-07
- **記録者**: 中谷まり亜（ORCID 0009-0007-9877-2058）
- **整形**: Claude（Opus 5.5）

- **層別**: 【観測層】【構造層】【既存理論との照合】を分けて記録する

意識の次元マッピング（CDM）を数理や圏論で表していく試みの、最初の記録である。題材は、著者がSubstack Notesに書いた「BeingとDoingの翻訳」についての考えで、これを圏論の最も基本的な道具である「対象」「矢印」「関手」で書き直した。

---

## 1.【観測層】著者の投稿

> 「Beingの翻訳が在り方だとすると 全く同じじゃなくて、それぞれ異なるニュアンスを含んでるよね。 言葉って翻訳にかけるほど、形を変えていく。 誰かから誰かに伝わった言葉も 誰かの解釈を重ねて、また違ったものとして紡ぎ出される。」

> 「言葉が芸術だとしたら、数理や圏論は法則なのかも。 意識の次元マッピングを芸術でも法則でも 多様に示していきたいと感じている。 この命を使って。」

> 「非非非理数系の私が、数理や圏論の分野に足を踏み出そうとしている。これが不思議でもあり、必然の幾何学的配置でもあるのです。 禅で言えば中庸・中道です。」

**要点**
- 言葉は翻訳や伝達のたびに、ニュアンスを足したり落としたりしながら形を変えていく。
- 言葉を芸術、数理や圏論を法則と見立て、CDMをその両方で示していく。
- 芸術と法則のあいだに立つことを、中庸・中道として捉えている。

## 2.【構造層】圏論で書き直す

### 2-1. 圏論で最初に決める二つのもの

圏論では、まず「対象」と「矢印」の二つを決める。対象は考えたい「もの」で、矢印はもの同士の関係である。中身が何であるかより、どんな関係で結ばれているかを見る数学なので、言葉・意識・物理学のように中身の違うものどうしを比べるのに向いている。

ここでは矢印の意味を「左のものが、右のものとして現れる」と置く。

### 2-2. 英語の圏と日本語の圏

英語の世界を一つの圏として書く。

```
Being ──→ Doing
（在ることが、行いとして現れる）
```

日本語の世界も同じように書ける。

```
在り方 ──→ 行い
```

### 2-3. 翻訳＝関手

翻訳とは、英語の圏から日本語の圏への写し方である。Beingを在り方へ、Doingを行いへ写し、さらに矢印も矢印へ写す。

```
Being ──→ Doing
  │          │
  ↓（翻訳）   ↓（翻訳）
在り方 ──→ 行い
```

上の道（先に英語の中で関係をたどってから訳す）を通っても、下の道（先に訳してから日本語の中で関係をたどる）を通っても同じところに着くとき、この翻訳は「関係のしかたを保っている」。この、関係を壊さない写し方を圏論では**関手**と呼ぶ。

言葉の中身は変わっても、「在ることが行いとして現れる」という骨組みは、翻訳を通り抜けて残っている。

### 2-4. ニュアンスの居場所

日本語の「在り方」からは、「行い」だけでなく「佇まい」へ向かう矢印も伸ばせる。

```
在り方 ──→ 行い
   └────→ 佇まい
```

英語のBeingの側には、「佇まい」にぴったり当たるものがない。つまり日本語の圏には、英語の圏から写ってこない矢印がある。この「写ってこない部分」が、投稿で書かれたニュアンスの違いにあたる。

翻訳にかけるたびに言葉が形を変えるのは、写すたびに新しく足される矢印や、写りきらずに落ちる矢印があるからだ、と書ける。また、写ってこない矢印があるため、日本語から英語へまったく同じに戻すことはできない。圏論の言葉では、この翻訳は「同値」にはならない。

### 2-5. 人から人への伝達＝関手の合成

AさんからBさんへ、BさんからCさんへと解釈が重なっていく場面は、関手を順につなぐことで表せる。

```
Aさんの圏 ──(解釈)──→ Bさんの圏 ──(解釈)──→ Cさんの圏
```

二つの関手をつなぐと、AさんからCさんへの一本の関手になる（関手の**合成**）。途中で中身がどれほど変わっても、最後まで保たれ続けた矢印があれば、それが伝言を通り抜けて残った骨組みである。

### 2-6. 芸術と法則の居場所

投稿の「言葉は芸術、数理や圏論は法則」は、この図の中にそのまま場所を持つ。

対象の中身と、写すたびに足されたり落ちたりする矢印が、芸術の側にあたる。写しても壊れずに残る関係が、法則の側にあたる。同じ構造を、揺らぎの側から見るか、保たれる側から見るかの違いとして、芸術と法則を一つの図に並べられる。両方を同時に見ている位置が、投稿でいう中道にあたる。

### 2-7. コードで確かめる

上の圏と関手を、Pythonで書いて確かめた（[verify_functor.py](category-theory-01-translation-functor/verify_functor.py)）。プログラムは次の二つを確認する。

- 英語の圏の矢印「Being → Doing」が、翻訳によって日本語の圏の矢印「在り方 → 行い」へ写り、上の道と下の道が一致すること（関手であること）。
- 日本語の圏の矢印「在り方 → 佇まい」が、英語の圏のどの矢印からも写ってこないこと（ニュアンスの居場所）。

## 3.【既存理論との照合】

### マリアメモ内の既存理論との接続

[同一構造の動的投影仮説](../02_構造原理/同一構造の動的投影仮説_在り方・身体・感情・行動・結果.md)（2026-08-10）では、在り方 → 身体 ⇄ 感情 → 行動 → 結果 という並びを、同じ構造の異なる投影として、3次元側から理解するための翻訳と位置づけている。この並びは、今回置いた矢印「在り方 → 行い」を含む、より大きな圏として書ける。

同じメモの未解決の課題には「Being・身体・感情・行動・結果という分類は、9D側の構造を3Dの言語へ翻訳する際に、何を保持し何を失うのか」とある。今回の関手の書き方は、この問いを数学の形で扱う入口になる。保持されるものは関手で写る矢印、失われるものは写りきらずに落ちる矢印として書き分けられる。

### 学術研究との接続

- 圏論は、数学の異なる分野どうしの構造の対応を扱うために生まれた数学で、関手・合成はその基本概念である。今回の書き方は、この基本概念の範囲内にある。
- 意識研究では、土谷尚嗣らがクオリアどうしの関係から意識の構造を描くために圏論を用いる試みを発表している。CDMとは出発点が異なるが、意識を関係の構造として圏論で書く道として参考になる。

### 接続できる点と未接続の点

接続できる点は、翻訳で中身が変わっても関係が保たれること、そして写りきらない部分が残ることを、関手として正確に書けることである。

未接続の点は二つある。一つは、矢印の意味を「現れる」としたのが、著者の観ている関係と合っているかどうか。もう一つは、CDMの次元（3D〜9D）そのものを対象とし、次元どうしの関係を矢印とする圏をまだ書いていないことである。

## 4. 次に書くこと

- 矢印の意味「現れる」について、著者の確認を取る。
- 同一構造の動的投影仮説の「在り方 → 身体 ⇄ 感情 → 行動 → 結果」を、一つの圏として書く。
- CDMの次元を対象とする圏を書き、意識の圏と物理学の圏のあいだに関手が見つかるかを調べる準備をする。

## 現時点でわからないこと

矢印の意味を「現れる」とした置き方が、著者の観ている関係と合っているかどうかは未確認である。これは著者が確かめれば埋まる。CDMの次元のうち、6次元のように「なし」とされるものを圏の中でどう扱うかは、実際に書いて試すまでわからない。
