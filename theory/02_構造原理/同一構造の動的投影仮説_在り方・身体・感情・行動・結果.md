# 同一構造の動的投影仮説｜在り方・身体・感情・行動・結果は同じ構造の異なる影である

タグ: #意識の次元マッピング #同一構造 #動的投影 #感情 #Being #諸行無常

---

## 背景

2026年8月10日の観測で、感情を「変える対象」ではなく、現在の在り方を読むセンサーとして捉える視座が立ち上がった。さらに観測を進める中で、

「もしかすると構造(幾何学模型)があって、壁に映し出される影を、とある方向から見れば感情として映し出されて、とある角度から見れば行動として映し出されてってとこまでわかってたけど、そのひとつに在り方も入るかんじかも？ つまりBeing は各次元ごとに違うよ😊」

という像へ展開した。

その後、人間が理解するための説明順として、

「構造的に在り方⇒身体⇒感情⇒行動⇒結果の順番のほうがわかりやすいかも。本来同時なんだけど、人間からするとって感じ。」

という整理が加わった。

## 考察の要点

在り方（Being）・身体・感情・行動・結果は、独立した原因と結果の列ではない。**同一の基底構造が、異なる観測角度・条件から同時に映し出された複数の投影である。**

ただし人間は同時発生する構造をそのまま認識しにくいため、時間軸へ展開すると、**Being → 身体⇄感情 → 行動 → 結果**という連鎖として読むことができる。

## 理論の詳細

**まり亜仮説／未検証**

本体モデルには本来、固定した先後関係はない。

神聖幾何学の立体模型の内部に光を置き、模型を回転させながら壁へ影を映すように、一つの構造からまったく異なる像が連続して現れる。Being、身体、感情、行動、結果は、この異なる影に相当する。

感情は3次元では身体的な生体反応として現れ、4次元では現在状態を読むセンサーとして観測される。同様にBeingも絶対的な根本原因ではなく、次元・観測位置によって異なる姿をとる投影の一つである。

人間向けに直列化すると、

**Being → 身体 ⇄ 感情 → 行動 → 結果**

と表せる。ただしこれは因果の絶対順序ではなく、同時構造を時間軸上へ翻訳した近似表現である。各投影は相互に影響し、次の投影条件そのものを変化させるため、並列性と連鎖性は同時に成立する。

## 統合対応表

| まり亜理論の概念        | 対応する既存理論・現象                | 対応の性質       |

| 一つの構造から複数の影が現れる | 立体物の投影・影の幾何                | 構造的アナロジー    |
| 角度・条件で現れ方が変化する  | 現像前演算仮説の「進入角度・条件差」         | 既存まり亜理論との接続 |
| Beingも投影の一つである  | ホログラフィック原理と状態情報仮説のBe／状態モデル | 更新・拡張関係     |
| 同じ形が完全には反復しない   | 諸行無常                       | 構造的アナロジー    |

## 未解決の課題

* 一つの投影が次の投影条件を変えるフィードバック構造を、どのように表現できるか。
