# 同一構造の動的投影仮説｜Being・身体・感情・行動・結果は同一構造の異なる投影である

タグ: #意識の次元マッピング #同一構造 #動的投影 #Being #感情 #時間

---

## 背景

2026年8月10日、感情を現在状態を読むセンサーとして観測している途中で、Beingそのものの位置づけが変化した。

「もしかすると構造(幾何学模型)があって、壁に映し出される影を、とある方向から見れば感情として映し出されて、とある角度から見れば行動として映し出されてってとこまでわかってたけど、そのひとつに在り方も入るかんじかも？ つまりBeing は各次元ごとに違うよ😊」

さらに、

「構造的に在り方⇒身体⇒感情⇒行動⇒結果の順番のほうがわかりやすいかも。本来同時なんだけど、人間からするとって感じ。」

という整理が生まれた。

## 考察の要点

在り方（Being）・身体・感情・行動・結果は、**同一の基底構造が異なる観測角度・条件から現した複数の投影である。**

`Being → 身体 ⇄ 感情 → 行動 → 結果` は全次元共通の因果順序ではなく、線形時間を用いる3次元側から構造を理解するための直列的な翻訳として位置づける。

## 理論の詳細

**まり亜仮説／未検証**

神聖幾何学の立体模型の内部に光を置き、角度や条件を変えながら壁へ影を映すと、一つの模型から異なる像が現れる。Being、身体、感情、行動、結果も、このような同一構造の異なる投影として捉える。

次元によって、その関係の見え方も変化する。

| 次元 | 時間・構造の見え方 |
|---|---|
| 3D | 過去→現在→未来の線形時間。原因と結果の連鎖として読む |
| 4D | 未来を先に観測し、未来→現在→過去へ観測方向が反転する |
| 5D | 「いまココ」の瞬間を線形につないで時間と認識していたと腑に落ちる |
| 6D | 時間と主体の境界が消え、時間的因果も成立しない |
| 7D | 感情などに仕分けられる以前の生の情報コードを受信する |
| 8D | 情報の蓄積からパターン・法則を観測する |
| 9D | 基底構造と、その構造から現れる複数の投影を同時に観測する |

したがって、5Dの「すべてはいまココにある」という感覚と、9Dの「Being・身体・感情・行動・結果が同一構造の異なる投影として見える」という構造認識は、同じ「同時」という語を使っても解像度が異なる。

「動的」とは、6D以降に時間的な因果連鎖があるという意味ではなく、同一構造から現れる投影が、観測角度や条件によって固定された一枚絵にならないことを指す。

## 統合対応表

| まり亜理論の概念 | 対応する既存理論・現象 | 対応の性質 |
|---|---|---|
| 一つの構造から複数の投影が現れる | 立体物の投影・影の幾何 | 構造的アナロジー |
| 角度・条件によって現れ方が変わる | 現像前演算仮説 | 既存まり亜理論との接続 |
| Beingも投影の一つである | ホログラフィック原理と状態情報仮説のBeモデル | 更新・拡張関係 |
| 似た投影も完全には反復しない | 諸行無常 | 構造的アナロジー |

## 未解決の課題

* 基底構造そのものは安定しているのか、それ自体も変化・階層化しているのか。
* 3D・4Dで因果やフィードバックとして見える関係を、時間を用いない6D以降ではどのように記述できるか。
* Being・身体・感情・行動・結果という分類は、9D側の構造を3Dの言語へ翻訳する際に、何を保持し何を失うのか。
