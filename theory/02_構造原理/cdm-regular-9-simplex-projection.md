## 3. 数学として確かめられること

ここからはユークリッド幾何学の具体的なモデルを扱う。S1の実装の復元ではなく、S0の説明に合う独立した構成例である。

### 3.1 10頂点・45辺の正9単体

正n単体は、n+1個のアフィン独立な頂点を持ち、異なる頂点間の距離がすべて等しい単体である。n=9では10頂点となり、頂点を2つ選ぶ組は `10×9÷2=45`。この45組が辺になる。[NPTELの標準単体の定義](https://archive.nptel.ac.in/content/storage2/courses/111101002/images/node360.html)と、[John Burkardtによる正単体の座標構成](https://people.math.sc.edu/Burkardt/m_src/simplex_coordinates/simplex_coordinates.html)を参照。

辺長1の具体例として、10次元空間の標準基底を `e_i`、全成分が1のベクトルを `1` として、

```text
v_i = (e_i - (1/10)1) / √2    (i=1,...,10)
```

と置く。全点は `Σx_i=0` という9次元部分空間内にあり、`v_i-v_j=(e_i-e_j)/√2` なので、i≠jなら距離は1になる。10次元で書いたのは対称な座標表示のためであり、この形のアフィン次元は9である。

図で45本の線を描くのは、正9単体の頂点と辺を表す方法である。単体自体には三角形の面や、さらに高次元の面・内部もある。

### 3.2 回転と平面への正射影

上の9次元部分空間に正規直交座標を取り、頂点を `x_i∈R^9` と表す。回転を `R(t)`、固定した平面への正射影を平面座標で表す行列を `P` とする。

```text
R(t)^T R(t) = I, det R(t) = 1
P は 2×9 行列、P P^T = I_2
影の点 y_i(t) = P R(t) x_i
```

回転後も元の辺長は `||R(t)(x_i-x_j)||=1` のまま。影では `||P R(t)(x_i-x_j)||≤1` となり、向きによって長さが異なり得る。正射影で長さが縮む性質と、直交変換が長さを保つ性質は、[IIT Madrasの線形代数教材](https://www.ee.iitm.ac.in/~uday/notes/linalg/orth.html)を参照。本稿の式からも直接確かめられる。

異なる元の点が影では重なることもある。平面上では、10個の相異なる点の全45距離を同じ正の値に保てない。平面上の相互等距離点は最大3個だからである。

回転の選び方によっては影の長さが変わらない場合もある。「どんな回転でも必ず長短が入れ替わる」とまでは言わない。固定した構造と、構造に対する投影面の向きの変化を分けて考える。

ここで採用したのは正射影である。透視投影、斜めの投影、画面表示の拡大縮小を含む場合は条件が変わる。S1がどの方法を使ったかは未確認のまま残す。

### 3.3 数学内部での区別

- **中心から全点が等距離**であることと、**全点どうしが等距離**であることは異なる。円周上の点は前者を満たしても、一般には後者を満たさない。六方向のメモと正9単体をつなぐときの重要な確認点になる。
- 正9単体の重心は10頂点とは別の点。重心を「観測点」と読むなら、それは追加の対応案となる。
- 等距離でも、各頂点は別の頂点として区別できる。一方、どの行動を選ぶかという規則は、この距離だけからは導かれない。
- 完全グラフK10として描いた線は無向のつながりであり、時間順序・因果方向・作用の機序を持たない。影の近さだけから原因と結果を判定できない。

## 4. 共有説明の6項目を、研究可能な対応案にする

S0の表は出発点として全文を保持し、以下には本稿による評価を別に置く。「数学の性質が成立する」ことと、「その性質がCDMの観測を記述できる」ことは、別の確認項目である。

| 共有説明の着眼点 | 数学で成立する内容 | CDMへの対応の現在地 |
|---|---|---|
| 等辺 | 正9単体の全頂点対の距離は等しい | 有力な比較候補。CDMで何を点・距離と呼ぶか、中心からの等距離か全点対の等距離かを確かめる必要がある |
| 壁に映る影 | 高次元の点を平面などへ射影できる | 原典の「構造と影」に接点がある。CDMの現れ方が線形射影で記述できるかは未確定 |
| 元の形を変えずに影が変わる | 回転は距離を保ち、射影後の距離は向きに依存し得る | 構造と現れ方を分ける対応案。「メソッドで変えたわけではない」という観測の意味や主体・操作の有無は、回転の定理からは決まらない |
| 観測上の等辺性と行動上の区別 | 等距離の頂点は区別されたまま存在する | 区別を保つ表現として比較できる。原典の「観測上の等辺性 ≠ 行動上の無差別」は、行動についてのCDM内部の区別であり、正単体だけから導出したものではない |
| 3次元で見える一本の因果の線 | 網から経路を選び出すことはできる | 比喩・構造的アナロジーの候補。因果の向きと時系列には追加の定義・記録が要る。CDMの3次元を画面の2次元や数学の3次元空間へ機械的に対応させない |
| 6次元の鏡面、相反するものがゼロになる | ベクトルなら `a+(-a)=0`。原点対称は `x→-x`、超平面に関する鏡映は別の操作 | 未確定仮説。相殺して得る零ベクトルと、CDMの主体・対象という区別が成立しない状態との同一性は示されていない |

最後の項目では、数学的に `a+(-a)=0` となっても、aと−aという2つの対象を記述する枠組みは残る。さらに、9次元での `x→-x` は全方向の反転であり、1枚の超平面での鏡映と同じ操作ではない。「鏡面」という語の対応先も、今後の検討対象にする。

S0にある「影で近く見える点は原因と結果に見えやすい」「運がよかった出来事も別の向きでは近く見える」という読み方は、図から得た解釈の候補として保持する。数学は、現実の因果・偶然・運の機序をこの図によって実証してはいない。
